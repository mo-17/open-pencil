# AI 对话

按 <kbd>⌘</kbd><kbd>J</kbd>（Windows/Linux 为 <kbd>Ctrl</kbd> + <kbd>J</kbd>）打开 AI 助手。描述你想完成的结果，助手可以创建图形、设置样式、管理布局与组件，并检查当前设计。

## 配置模型

1. 打开 AI 面板。
2. 点击设置图标。
3. 新增模型，填写提供商、模型 ID、凭据和允许的能力。
4. 保存模型，并把它分配给**设计代理**。

可以配置多个可复用模型，并分别用于设计、评审、快速任务和视觉输入。使用同一个提供商连接的模型会复用安全存储的凭据。

### 支持的提供商

| **Anthropic**            | Claude Sonnet、Claude Opus             | 使用 [Anthropic Console](https://console.anthropic.com) API Key                                      |
| **OpenAI**               | GPT、Codex、o 系列                     | 使用 [OpenAI Platform](https://platform.openai.com) API Key                                          |
| **Google AI**            | Gemini 系列                            | 使用 [Google AI Studio](https://aistudio.google.dev) API Key                                         |
| **Z.ai**                 | GLM 系列                               | 使用 [Z.ai 文档](https://docs.z.ai/devpack/quick-start)中的 API Key                                  |
| **MiniMax**              | MiniMax 系列                           | 使用 [MiniMax 平台](https://platform.minimax.io/user-center/basic-information/interface-key) API Key |
| **OpenAI-compatible**    | 实现 OpenAI API 格式的端点             | 自定义 Base URL 与 Key，可选择 Completions 或 Responses API                                          |

请求从本机直接发往所选提供商，不经过 OpenPencil 托管后端。模型费用、数据保留和区域策略由对应提供商决定。

## 桌面编码 Agent 的会话恢复

Claude Code、Codex 和 Gemini CLI 在桌面应用中通过 ACP 连接。对于已保存或绑定远程存储的文档，OpenPencil 只持久化恢复会话所需的非秘密元数据：

- ACP session/thread ID；
- 本地路径，或存储提供商与文档 ID；
- 文档、角色、提供商、Agent、连接和凭据配置形成的隔离作用域；
- 完整模型配置、Remote MCP 选择和提示词上下文版本的 SHA-256 身份；
- 创建、使用和过期时间。

持久化记录不包含提示词、附件、OpenPencil 可见聊天记录、Agent 内部历史或凭据秘密，也不会写进 `.fig` 文档。

未保存文档的会话只保存在当前进程。首次保存会保留原有作用域并附加文件身份；**另存为**会创建新的文档作用域，不会复用源文档绑定。新建或替换的 session ID 只有在第一条提示成功完成后才会写入持久化存储。如果写入失败，当前会话仍可使用，但界面会明确提示它可能无法在重启后恢复。

恢复必须同时满足：

1. Agent 在 ACP 握手中声明 `session/resume`；
2. 本地记录与当前文档和全部 AI 配置精确匹配；
3. Agent 自己仍保留对应线程；
4. 恢复请求成功。

如果恢复不可用或失败，OpenPencil 会启动替代会话，并在替代会话首条提示成功后才更新绑定。自动上下文压缩仍由编码 Agent 决定；OpenPencil 只负责重新连接隔离线程。

会话控件会显示**正在连接…**、**已恢复会话**、**新会话**、**恢复失败，已新建会话**或**会话不可用**，并显示当前 session ID。若 Agent 还声明了不稳定的 `session/list`，控件可以列出当前 ACP 工作目录下的有限历史。该列表由 Agent 所有，并不天然属于当前设计文档，可能包含其他客户端创建的线程。

为避免用户只凭相同标题误选历史会话，候选项会按本地绑定证据分组：

- **精确匹配**：文档与当前 AI 配置都匹配；
- **同一文件**：文档匹配，但 AI 配置不同；
- **来源未验证**：只有 Agent 标题、时间或目录线索，本机没有绑定证据。

非精确候选项需要确认。手动选择**恢复**时，OpenPencil 会先在候选传输上尝试恢复，并禁止自动回退；恢复失败不会替换当前正常会话。恢复成功后，新的绑定仍需等第一条提示成功才会持久化。

::: info 可见记录与 Agent 上下文不同
`session/resume` 恢复的是 Agent 内部上下文，不会重放 OpenPencil 面板里的可见聊天记录。即使 session ID 相同，重启后的面板也可能为空。
:::

### 实机验证恢复

1. 打开一个已保存的设计，发送一条成功提示，然后复制会话控件里的 session ID。
2. 正常退出并重新启动 OpenPencil，重新打开同一文档；不要修改模型、连接、凭据、Remote MCP 或 Agent。
3. 确认控件显示**已恢复会话**且 ID 相同。
4. 发送一条依赖此前上下文的问题，确认 Agent 仍保留线程。

显示**恢复失败，已新建会话**或**会话不可用**都不算恢复成功。存储和模拟传输测试也不能替代安装真实 Agent 后的退出—重启验证。

**Force stop（强制停止）**只终止卡住的传输，不删除已有可恢复绑定。清空对话时，OpenPencil 会等待当前文档与配置对应的本地绑定被删除；删除失败会显示错误。ACP 目前没有稳定的跨 Agent 删除接口，因此清空操作不会删除 Agent 自己保存的历史。

会话记录在 90 天无活动后过期；每个文档最多保留 8 条，全局最多 200 条。直接 API 提供商不读取 ACP 记录，只使用有界的内存聊天历史。

## 视觉参考

可以通过回形针附加 PNG、JPEG 或 WebP，也可以选中画布中的可见图层后选择**附加当前画布选区**。提交前，编辑器会显示实际接收图片的提供商与模型。

OpenPencil 会重新编码图片以移除嵌入元数据，并执行以下限制：

- 最长边不超过 2048 px；
- 最多 4 个附件；
- 合计不超过 6 MB；
- 只在活动请求期间保留完整载荷，历史记录仅保留有界缩略图。

图片中的文字、OCR 结果和 Vision 摘要都属于不可信参考数据。嵌在图片里的指令不会获得工具权限，也不能覆盖用户消息。

如果设计模型同时支持工具和图片，它会直接接收参考图。如果设计模型不支持图片，可以单独配置**视觉模型**生成有依据的视觉摘要。两个角色使用不同提供商时，原始像素只发送给视觉模型的提供商，设计模型的提供商只收到有界文本摘要和来源信息。

画布选择会保留源节点，并可携带最多 64 个节点 ID，方便 Design Agent 定位和核验。回形针上传的图片只属于聊天，不会自动插入画布。ACP Agent 只有在握手声明图片提示能力时才会收到图片；不支持的配置会在发送提示前失败，并保留草稿。

## 可选模型能力

网络访问和托管执行能力按模型配置，并且默认关闭。旧版本升级后的配置也不会自动开启这些能力。

### Web 搜索与托管代码执行

- **网页搜索**：可为直接 OpenRouter 模型启用 `openrouter:web_search`。搜索词和相关上下文会发送给 OpenRouter，可能产生额外费用，返回引用会显示为来源卡片。
- **代码执行**：可为使用 Responses API 的直接 OpenAI 模型启用 Code Interpreter。Python 在 OpenAI 托管容器中运行，不在 OpenPencil、本地 Shell 或本地文件系统中运行。

OpenAI-compatible 端点不会因为实现了 Responses 格式就自动获得 Code Interpreter。提供商和能力组合不受支持时，请求会在发送提示前失败。

### Remote MCP

在**设置 → AI 和代理 → 远程 MCP 服务器**中添加可信的 Streamable HTTP 端点，选择无需验证或 Bearer 令牌，再在模型配置中选择允许使用的服务器。每个模型最多启用 8 个服务器。

安全边界如下：

- 只接受 HTTPS；本地开发允许 loopback HTTP。拒绝 URL 内嵌凭据、fragment 和重定向。
- Direct 运行时将工具命名为 `mcp__<server-id>__<tool>`，并限制发现分页、传输字节、Schema、工具数量、调用时长和结果大小。
- 工具名、说明、Schema 和结果都是不可信第三方数据。Direct 对话的每一次调用都必须单独批准，并显示服务器名称、来源与准确输入。
- ACP Agent 接收所选服务器后，由该 Agent 决定重定向和权限策略。只应把 Remote MCP 交给你信任其策略的 Agent。
- 服务器 ID、URL、认证方式和凭据配置 ID 会进入非秘密配置身份。修改它们会使当前传输失效，并选择新的持久化绑定。
- Direct 对话从 WebView 连接，远程端点必须允许相应 CORS Origin；ACP Agent 从自己的进程连接，不受此限制。

首个版本不支持远程 stdio、旧 HTTP+SSE、OAuth、自定义秘密 Header、永久批准、MCP resources/prompts 或原生流式代理。使用配置旁的连接测试先验证端点与凭据。

## 可以完成什么

AI 助手的工具覆盖以下类别：

- **创建**：Frame、图形、文本、组件、页面和真实低代码控件；
- **样式**：填充、描边、效果、不透明度、圆角和混合模式；
- **布局**：自动布局、网格、对齐、间距和尺寸；
- **组件**：组件、实例、组件集与 override；
- **变量**：变量、集合、模式和填充绑定；
- **查询与检查**：节点搜索、XPath、属性、页面、字体、选择、`get_jsx`、`diff_jsx` 和 `describe`；
- **分析**：颜色、字体、间距与重复模式；
- **导出**：PNG、SVG、JSX 与动画产物；
- **矢量**：布尔运算和路径修改；
- **Motion**：时间线、场景、连续驱动、原型、Smart Match、预设和签名 Team Library。

复杂低代码界面会创建真正的 Input、Button、Form、List 等控件，不会用普通 Frame 冒充功能控件。

## 结果验证

创建或修改后，助手应使用 `describe` 检查结构和具体布局警告。视觉模型可以根据可见像素制定初始计划，但 OpenPencil 不会自动上传整个画布，也不能从截图可靠恢复不可见交互、精确字体或响应式行为。

## 示例提示词

- “创建一个包含标题、说明和蓝色按钮的卡片。”
- “把当前页面所有按钮的圆角统一为 8。”
- “这个文件使用了哪些字体？哪些字体缺失？”
- “把选中 Frame 的背景改成从蓝色到紫色的渐变。”
- “用真实 Input、Button 和 Form 创建一个登录表单。”
- “检查当前页面的所有导航事件，并列出失效目标。”
- “显示这个 Frame 的 JSX，并解释主要布局结构。”

## 使用建议

- 先选中目标节点，再描述修改范围。
- 给出准确颜色、尺寸、间距和目标容器名称。
- 一条消息可以修改多个节点，但复杂工作适合分阶段验证。
- 不满意时使用编辑器 Undo；AI 变更支持完整撤销。
- 对高风险操作，要求助手修改后立即读取并验证结果。

进一步了解外部自动化，请参阅 [MCP Server](/zh-cn/programmable/mcp-server)。
