# 用户指南

OpenPencil 是一款兼容 Figma 的开源设计编辑器，完全在本地运行，原生支持 AI，并且可以编程扩展。本指南将帮助你高效使用编辑器。

::: tip 跨平台快捷键
本指南中的键盘快捷键采用 Mac 标记：<kbd>⌘</kbd> = <kbd>Command</kbd>（Windows/Linux 上为 <kbd>Ctrl</kbd>），<kbd>⌥</kbd> = <kbd>Option</kbd>（<kbd>Alt</kbd>），<kbd>⇧</kbd> = <kbd>Shift</kbd>。
:::
