# 低代码应用

OpenPencil 可以把设计页面编译为可运行的 React + TypeScript + Tailwind 静态单页应用（SPA）。你仍然使用普通的 Frame、Text、Button、Input、组件与自动布局完成视觉设计，再通过低代码属性为节点添加状态、表单、导航、API、Supabase、工作流和国际化行为。

## 可以构建什么

- 营销页面、产品页面、仪表盘、表单和数据列表。
- 使用 `react-router-dom` 的多页面 SPA。
- 带本地校验、远程校验和提交工作流的受控表单。
- 使用 Supabase Auth、数据库查询/变更和 Storage 上传的应用。
- 文档级或页面级状态，例如筛选器、开关、计数器和界面状态。
- 支持语言目录、RTL 方向和语言切换器的 i18n 应用。
- GA4、Plausible 或 PostHog 分析，以及受控的静态 Head/CSS 扩展。
- 普通 Tailwind 或受支持的 shadcn/ui 控件输出。
- 可部署到 Netlify、Vercel、Cloudflare Pages 或其他 SPA 主机的静态文件。

## 可选应用模式

在左侧页面面板开启**应用模式**，再将业务页面设为**应用页面**，为每页选择一个顶层 **入口 Frame**，设置路由及起始页。**参考页面**和**组件页面**仍可正常编辑和保存；它们不生成业务路由，共享组件仍可被应用页面的实例引用。没有分类的页面也不自动加入应用。

入口 Frame 可以放在画布的任意位置。生成应用从入口的局部原点开始，入口以外的参考内容留在设计中；页面的设备适配策略作用于所选入口；配置共享框架后，则作用于最外层框架。导航事件仍使用已有的内部路由和参数配置。动态路由的必填参数需要由调用方提供。

起始页须使用不带查询参数或锚点的静态路径。动态或通配页面仍可作为业务跳转目标，但不能选为首页；已有配置不符合条件时会提示修复，不会自动更换首页。

应用模式默认关闭，旧文档无需迁移。关闭后沿用原有设计和代码导出范围；模式切换及页面设置支持撤销，并保存在 `.fig` 中。SVG、图片及普通设计文件导出继续使用各自的原有选择范围。

应用模式下，网页预览在同一文档自动重编译后保留已声明的文档状态及当前业务路由，包括具体路径参数、查询参数和锚点。同页节点选择保留当前 URL；手动选择其他静态应用页会切换目标。编辑器同步替换当前浏览器历史项，业务导航及浏览器返回、前进无需多走额外的同步步骤。切到参考稿不会让应用跳页。打开其他文档、修改文档状态声明、关闭应用模式或手动重启预览会清除这些临时状态；它们不会写入设计文件。

自动重编译会更换预览页面；此前的导航历史栈及未声明的页面局部状态暂不恢复。

应用配置需使用 `.fig` 保存。导入 `.pen` 的源保真写出仍只支持 Motion 修改；添加应用配置后，应另存 `.fig`。

入口未选择、已删除或不属于当前页面时，应用编译会给出诊断。入口之外的原型、Motion 或行为目标必须检查其诊断，不能假定它们已被自动搬入应用。嵌套路由和任意组件内部状态恢复仍需后续实现；此模式也不会自动转换既有目标不支持的运行时功能。

### 页面会话与导航

应用页面尚未保存策略时，**返回时的页面状态**显示**未设置（沿用原有行为）**。主动选择**每次访问重置**会明确启用重置；选择**本次会话内保留**后，React/Vue 会恢复绑定到已声明可写页面状态的值及窗口滚动位置。例如列表保留筛选条件和分页，打开详情编辑草稿后再返回；计算状态根据恢复的输入重新计算。明确保存重置策略后，参数或查询切换也会重置同一路由组件；旧页面未保存策略时沿用原有路由组件复用行为。

缓存按页面 ID、具体路径与查询字符串隔离；不同商品 ID 或查询条件各有草稿，只改变 hash 则使用同一份会话。同一文档自动重编译会恢复这些值。打开文档、手动重启预览、切换框架、修改页面状态声明或初值、路由或入口配置会清除缓存。只有保留偏好写入 `.fig`，运行值不写回设计。

启用保留策略的 Tauri 预览会重建 iframe，等新运行时准备好后恢复已声明的值；服务端的热更新确认不作为运行时已生效的依据，未绑定控件的内部值不在恢复范围内。未启用这项策略的预览继续沿用原有热更新行为。

缓存仅在本次运行的本地内存中，最多 64 个页面实例、4,096 个可移植值及 256 KiB 快照，并预留协议开销。总量超限时移除最早更新的实例；File、DOM、凭据和后台存储不会自动采集，未绑定控件内部值和嵌套滚动容器不在恢复范围内。作者自行放入页面状态的普通字符串或对象会被包含，系统不会根据内容识别敏感值。Flutter 等源代码目标对不支持的保留策略显示警告；导出的网页刷新后也会开启新会话。

导航动作支持**跳转页面**、**替换当前页**与**返回上一页**。替换不会增加浏览器历史项；返回只使用本应用记录的历史，没有可用历史时，以替换方式前往作者指定的**无历史时的目标**。此地址须是内部具体路径并提供必要参数，可携带查询与 hash。自动重编译保留当前 URL，但导航历史重新开始，此时返回会使用兜底路由。Flutter 生成原生跳转、替换与返回/兜底动作；其他不支持的目标明确报告诊断。

### 进入条件与离开确认

应用页面可选配**进入条件**和**离开确认**。每组两个字段先保留为草稿，点击**应用规则**才一起保存；**取消**恢复已保存值，**移除规则**删除配置。支持撤销重做及 `.fig` 保存重开。关闭应用模式后规则休眠，原有设计导出继续保留。

进入表达式读取文档状态名及目标路由的 `$params`、`$query`，例如 `hasAccess && $params.productId !== "blocked"`。只有严格的布尔 `true` 才允许进入；同时配置另一个有效应用页面的具体内部兜底路径，例如 `/home?reason=denied`。已配置规则中的空／非法表达式或非 true 结果不会放行；未配置规则的页面沿用原行为。非法目标、自跳和兜底循环会被拒绝。已有登录保护先于业务条件执行。这些规则控制导航和展示，数据权限仍由服务端执行。

离开表达式读取当前页面或文档状态，例如 `detailDraft !== ""`，并配置纯文本确认消息。**继续编辑**保留当前页面和草稿，**离开页面**继续本次跳转。确认不会自动保存或清空数据；业务保存成功后，应由既有提交／保存流程更新“未保存”状态。页面的重置／保留策略继续决定运行值是否保留。

React/Vue 的生成导航、共享框架导航和预览跳转请求都经过规则。参数或查询变化也可触发离开确认，仅改变片段不触发。本次路由器创建的历史记录支持取消浏览器返回／前进；未知历史记录、手工修改 history 和跨文档离开的拦截受浏览器限制，刷新／关闭使用原生离开提示。Flutter 等原生／源代码目标对这些可选策略给出不支持提示。

配置守卫的微前端导出会明确拒绝，直到宿主能够承担这套路由契约；未配置守卫的微前端导出保持原行为。

修改守卫规则或输入声明后，旧预览构建的恢复权限会失效；带守卫且未连接后台的 Tauri 预览重新创建 iframe，避免把旧运行时的 HMR ACK 当作规则已更新。

### 可选共享页面框架

在参考页面或组件页面上，用普通 Frame 设计桌面侧栏与顶栏，或手机顶栏与底部导航。在框架里放一个空的纵向或横向自动布局 Frame，作为业务页的内容区；内容区可以嵌套在普通 Frame 中。

在应用模式面板选择**共享框架**与**内容区**，点击**应用框架**后，两项引用一起保存。选择期间只是草稿，**取消**恢复已保存的配置；**移除框架**恢复各业务页原有的入口布局。应用与移除都支持撤销，配置随 `.fig` 保存和重开。

每个生成路由会把自己的入口放入内容区，宽度填满可用区域，高度保留原设计值。原框架、空内容区和业务入口仍可独立编辑，编译不会移动它们。共享导航使用现有跳转动作；跨页计数等值请使用文档状态。共享框架不会读取某个业务页的局部状态，其来源页面也不能带局部状态、页面事件或工作流。

引用丢失、内容区非空、祖先受保护或框架行为不支持时，会给出诊断并保留配置供修复，不会自动选择其他框架。React、Vue 生成应用与 Flutter 源码生成共用这一规则。本功能不增加嵌套路由，也不保证跳页后保留所有局部控件或表单值。

## 桌面版与浏览器版

| 能力                               | 桌面应用        | 浏览器应用                            |
| ---------------------------------- | --------------- | ------------------------------------- |
| 编辑设计与低代码属性               | 支持            | 支持                                  |
| 本地实时预览面板                   | 支持 React／Vue | React 使用浏览器 Worker；Vue 暂不支持 |
| 预览面板中的部署操作               | 支持            | 不支持                                |
| CLI `compile` / `build` / `deploy` | 可在终端运行    | 可在终端运行                          |
| 通过 MCP/AI 操作当前文档           | 支持            | 取决于所连接的工具                    |

React 可直接在 Web 编辑器中预览，Vue 预览使用桌面 sidecar。浏览器工作流需要构建或部署时，请先保存 `.fig` 或 `.pen` 文件，再从终端运行 `openpencil build` 或 `openpencil deploy`。

## 预览同步方式

在预览设置中选择同步方式。默认的**自动**模式会在停止输入 400–1,000 毫秒后同步；**保存后**模式仅在当前文档保存成功后触发，排队任务启动时编译最新编辑内容。取消或失败的保存、自动恢复快照都不会触发。**手动**模式只通过刷新按钮更新；**实时**模式在每次修改后请求更新。各模式均串行执行并合并排队修改，偏好保存在本设备。已连接的 NestJS 预览始终自动同步。

在基于本仓库的 Tauri 开发环境中展开 **Flutter 模拟器预览**，查找已启动的 iOS 或 Android 模拟器，选择设备后点击**启动**。Flutter 在独立原生窗口中运行并使用同一同步方式；设计模式的快照来自当前页面，切换页面会结束旧会话；应用模式包含完整应用，切换应用页面保留同一会话。热重载保留运行状态。**停止**只结束编辑器启动的会话。需要预先安装 Flutter SDK、Bun、平台工具，并备好离线引擎和依赖缓存；Bun 须可由启动器 PATH 找到，Tauri 会保留这些目录并补充登录 Shell 路径。缓存缺失或工程需要第三方原生运行时插件时会显示错误，不会自动安装或升级。浏览器内启动 Flutter、正式安装包内置运行器尚未提供。不支持的功能继续显示编译警告，原生平台代码变化需要停止后重新启动。React/Vue 网页构建、部署、iframe 选中与协作仍使用各自的目标能力。

## 页面设备适配

清除选中图层，在设计面板的**页面**区域选择**设备适配**。这是保存在 `.fig` 中的页面布局策略，支持撤销与重做。预览中的手机、平板或桌面尺寸只改变查看区域，不会修改这个策略或缩放编辑器画布。

| 模式           | 生成页面的行为                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| **固定尺寸**   | 保留原有几何与输出行为；旧页面没有配置时使用此模式。                                                     |
| **按宽度缩放** | 将整个可见设计等比缩放到可用内容宽度，归一化负坐标，并保留缩放后的高度、滚动与点击区域。                 |
| **响应式布局** | 页面填满可用宽度，最小高度为一个视口；顶层设计框架进入页面流，其内容高度跟随各断点下实际生效的自动布局。 |

使用**自动布局**、子项的**适应内容／填充**与**响应式**覆盖来编排响应式页面。自由布局中的绝对子项仍保留作者设置的位置，任意画布图形不会自动转换为响应式布局；要保持原构图，可选择按宽度缩放。调整生成页面的宽度会保留已挂载控件与本地运行时状态。设计范围为空或无效时，编译器会给出诊断并保留固定输出。

系统大字或可能换行的文案，建议配合自动布局和填充宽度，将控件高度设为**适应内容**，并设置合适的最小高度。固定高度控件在响应式模式下仍保留作者设置的高度；需要为预期字号、换行和内边距留足空间，或配置断点高度，页面适配不会自动把它放大。

React 与 Vue 共用按实际内容宽度测量的缩放逻辑，需要浏览器支持 CSS `zoom`。Flutter 将相同页面范围与策略投影到原生控件；当前网格支持按图层顺序排列及固定／比例列，自动轨道、显式网格位置与行轨道会给出诊断。子项独立对齐、无界拉伸，以及没有固定高度的垂直换行也保留明确的原生限制与诊断。其他不支持页面策略的移动端源码目标会提示不支持。交付前应检查目标诊断，并在实际浏览器或设备上验证。

Flutter 响应式**换行**支持主轴靠前、靠后、居中、两端对齐，以及每行／列内子项的交叉轴靠前、靠后、居中。行组分布的**自动**沿交叉轴靠前排列，**两端分布**将交叉轴剩余空间均分到各行／列之间，并保留最小行距；单行或交叉轴适应内容时不会增加间距。换行拉伸、基线和子项独立对齐会提示不支持，垂直换行仍须固定高度。响应式投影后会重新检查尺寸上下限：负数归零、非有限值省略、低于最小值的最大值提升至最小值，并给出编译警告。这些调整只影响生成控件，画布数据保持作者原值；分支中将限制设为 `null` 会移除该限制。

## Web 预览适配检查

在预览尺寸控件中选择设备预设或**自定义**，输入 240–2560 像素的宽高；拖动宽度滑块检查预设之间的尺寸。调整会保留 iframe、当前路由和未保存的表单值，设置只用于本次预览。

选择 100%–200% 的字体比例，可以放大 HTML 文字而不缩放整个页面。开启**键盘遮挡**会覆盖预览底部，遮挡高度最多为 300 像素或视口高度的 45%。用它检查关键控件是否被挡住；它不模拟原生键盘、视口缩小、聚焦自动滚动或 Flutter 系统大字设置。

开启**适配诊断**检查当前已渲染的 Web 预览，查看横向越界、文字裁切和固定高度文字风险。点击结果可定位画布节点，再根据建议调整适应内容、最小尺寸或填充宽度。有意设置的横向滚动、省略号和行数截断不作为这些问题报告。检查最多扫描 4096 个元素并显示 128 项；出现限制提示时，报告并不完整。空列表只表示此视口未检测到支持的诊断项，不能作为所有设备通过的结论。

字体模拟和检查依赖生成页面的 Web 预览通道；已连接的后端预览不提供此通道。Flutter 的真实 iOS／Android 大字体、键盘、横竖屏与安全区行为仍需单独验收；SVG、Canvas 和第三方嵌入视图内部绘制的文字也需单独检查。

## 编辑响应式分支

选中图层后打开**响应式**，一次选择一个断点；选项标出作用范围和已有覆盖字段数。每个字段显示**分支值**及继承来源。`sm`、`md`、`lg`、`xl` 在 640、768、1024、1280 CSS 像素起继承之前的最小宽度断点设置；`compact` 从基础设计继承，独立作用于 1280 像素以下。生成的 React、Vue 和 Flutter 布局在重叠区域优先采用紧凑分支已覆盖的字段，未覆盖字段继续按最小宽度断点累积。

修改值会创建覆盖，也可以点击固定图标，把当前继承值显式设为覆盖。恢复按钮只删除该字段的覆盖。尺寸限制的**无限制**与行高的**自动**会保存显式空值；恢复继承则删除这个空值设置。**清除**只移除所选断点，可一次撤销；其他断点和已编排的网格轨道保留。修改网格列数会明确将各列设为等宽。设置保存在 `.fig` 中，支持撤销和重做，画布基础几何保持不变。

点击**预览此宽度**，按所选断点打开 390、640、768、1024 或 1280 像素的网页预览。已挂载的预览会保留高度、路由和未保存的表单值。按钮只调整查看区域，沿用当前同步方式，不强制构建；手动或保存时同步的预览在刷新或保存前可能仍显示旧代码。不支持的网页预览会显示不可用提示。此按钮不切换 Flutter 模拟器设备。

## 推荐工作流

图层面板中的输入框、按钮等低代码节点使用与工具栏一致的控件图标；Tabs 等插件模块显示对应模块图标，普通外层画框保留布局图标。这些图标仅用于编辑器中的识别，不改变节点类型或 `.fig` 导出格式，也不意味着 Figma 能运行 OpenPencil 的低代码行为。

1. 使用普通 OpenPencil 节点完成页面设计。
2. 在设计属性面板中添加低代码行为：
   - **状态**：保存文档级或页面/节点级值。
   - **绑定**：绑定文本、表单值、可见性、列表数据和渲染条件。
   - **事件**：处理点击、提交、导航、API、Supabase 和工作流。
   - **校验**：配置必填项、文本/数字规则和远程校验器。
   - **响应式**：配置断点下的布局与可见性覆盖。
3. 在桌面应用中打开低代码预览面板。
4. 选择 Tailwind 或 shadcn/ui，并按需启用 i18n。
5. 验证交互、失败状态和路由后再构建与部署。

选中 `FRAME`、`FORM` 或 `LIST` 容器后，在**布局**区域使用**自动布局**开关，开启或关闭对子图层的自动排列。流向提供带文字的**自由布局、垂直布局、水平布局、网格布局**选项；要调整哪组子图层，就先选中它们所属的容器。

切到**自由布局**再选回同一流向，会保留已有的间距、内边距、对齐和尺寸模式；中间没有其他编辑时，相同配置会恢复原来的排列。给已有固定尺寸的容器开启自动布局时，会保留当前宽高；需要随内容变化时，再显式选择**适应内容**。**网格布局**保留已有行列轨道和间距，只初始化缺失的行或列，不会自动放大容器。Shift+A 仍使用原有的自动布局包裹行为。

如果在**自由布局**中移动了子图层，重新开启自动布局会按图层顺序与容器配置再次排列，而不是保留手动位置；撤销可恢复自由布局中的位置。每次切换流向只产生一步撤销，容器、子图层及受影响的外层容器、相邻图层会一起恢复。保存并重新打开 `.fig` 会保留切换后的布局和几何，撤销后保存也会保留恢复后的结果。

这些配置也会在自由布局下保存并重新打开后保留，再次开启自动布局时继续使用。主动改变导入容器的流向时，会重新计算排版，避免旧流向的几何缓存阻止重排。

输入框等叶子控件本身不排列子图层。它的父级使用自动布局时，属性面板会说明父级布局，并提供**选择父容器**入口，便于进入容器设置。宽度和高度旁持续显示当前的**固定、适应内容、填充**模式；点击模式菜单可切换，可用项仍取决于节点类型与父级布局，子图层的模式显示会对应父容器的排列方向。尺寸菜单切换可撤销，撤销时会同时恢复模式与包含宽高在内的布局几何。

用鼠标调整尺寸时，拖动预览和松手结果使用一致的布局，包括选中图层、外层容器与相邻图层。只调整宽度或高度时，该轴从**适应内容**或**填充**变为**固定**，另一轴保留现有的 Flex 尺寸规则。最小、最大尺寸限制仍然生效；按住 Shift 时，只要存在同时满足尺寸限制与宽高比的结果，就会保持原有比例。

网格子项的两个方向共用拉伸设置。调整尺寸若解除了该设置，另一轴会保留当前像素尺寸，但不会继续随网格变化而**填充**。

按 Escape 可取消调整尺寸。系统取消拖动、窗口失去焦点、画布失活，或切换选择、页面、文档，也会恢复预览前的状态；随后到来的鼠标移动或松手不会再应用这次拖动。完成一次调整只产生一步撤销，撤销与重做会一起恢复尺寸模式及所有受影响图层的尺寸和位置。

对于导入的 `.fig` 图层，调整会更新所操作的轴，另一轴保留原有导入布局。保存时会包含受影响外层容器与相邻图层的新尺寸和位置，并保留路径文字数据；撤销后再次保存也会使用恢复后的尺寸和位置。

第一次验证建议只创建一个页面：一个 Input 绑定到 `email` 页面状态，添加必填校验，再让一个 Button 更新状态或显示 Toast。确认预览中的值和错误状态正常后运行：

```sh
openpencil build app.fig -o dist
```

这样可以先验证“设计 → 绑定 → 事件 → 预览 → 构建”的完整链路，再引入 Supabase、多页面、工作流或 i18n。

## 表单绑定与校验

校验只会对受控值执行。Input、Textarea、Select、Radio、DatePicker、Checkbox 或 Switch 如果有校验规则但没有 `bindings.value`，请在绑定属性中选择**创建页面状态并绑定**。OpenPencil 会在一次可撤销操作中创建匹配的页面状态并写入引用绑定。

内置 AI 与 MCP 可以先审计，再进行可预览的修复：

1. 调用 `audit_form_controls`。
2. 调用 `ensure_form_value_bindings({ dry_run: true })` 检查计划。
3. 确认后再次调用工具并移除 `dry_run`。

工具不会覆盖已有的有效或无效绑定；无效目标会留给人工处理。审计默认最多返回 50 个控件，可配置到 200 个；结果包含 `total`、`returned` 和 `truncated`。一次修复若缺失绑定超过 199 个，会在修改前失败，请缩小范围后重试。

页面或表单范围的扫描会跳过可复用的 `COMPONENT` 与 `COMPONENT_SET` 主节点。组件主节点内部的字段不能绑定页面状态，应使用文档状态。如果导航或提交必须在校验成功后发生，请把动作配置在 FORM 的 `onSubmit` 事件上。

### 配置字段行为

交互属性面板提供输入类型、键盘输入模式、自动填充、无障碍名称、禁用/只读，以及适用的文本长度和数值约束。普通输入框支持文本、邮箱、密码、数字、电话、网址与搜索。将输入类型设为数字不会改变既有绑定的状态类型；字符串绑定保留空字符串，数字状态绑定把未完成输入保留为控件草稿，不会把它写成业务数字 0 或 NaN。

输入框与多行输入框在画布读取受支持的页面/文档绑定初值。密码显示遮罩，单行输入保持单行，文字裁剪在节点范围内。复选框显示初始勾选；复选组显示选项和数组中的已选值，也可读取受支持的初始状态选项源。这是设计初态投影；计算表达式、远程请求和业务事件仍需在预览中验证。

表格单元格、菜单及文件按钮文字复用画布的字体回退。所需字体加载完成后，分块画布会自动刷新，无需再修改节点来触发显示。最终外观仍取决于本机可用字体；这些低代码模块不会额外打包字体。

React/Vue 表单提交校验失败时，即使没有错误汇总，也会聚焦该表单第一个可编辑的错误字段，并跳过禁用、只读、隐藏或已移除的字段。原面板卸载后，晚到的校验结果不能把焦点移到替换字段。必填语义与关联错误文字保留无障碍支持，不会自动重放失败的业务提交。单选/复选组选项失焦会触发校验，数字上下限规则会拒绝非数字值。
组选项变化时也会立即更新校验。列表重复字段和可复用组件的多个实例，即使绑定同一个值，也会分别关联各自的错误提示。

编译后 FORM 接受重置时，表单内字段会恢复页面或文档状态的声明初值，包括混用的 INPUT 与模块字段，并清除校验错误。取消重置时，状态、显示值和错误保持不变。属于该 FORM 的条件字段即使暂时隐藏也会重置；Modal、Popover 和 Walktour 中通过浮层呈现的内容遵循各自的表单归属。独立受控、且不在编译后 FORM 内的输入仍遵循自身的受控值重置合同。

静态 Select 选项可以分别设置显示名称与实际值，并逐项禁用。原有字符串选项保持名称和值相同；配置了动态选项源时以动态源为准。请为控件设置无障碍名称，不能只依赖视觉占位文字。

选择器（SELECT）的配置现在位于设计面板靠前位置。可以分别编辑显示文字与提交值、调整顺序、禁用单项，并从列表选择默认项。修改当前默认项的提交值或删除该项时，选项与静态默认值一起撤销；绑定的业务状态不会被改写。重复提交值、空标签与失效默认值会给出提示。绑定值后静态默认值编辑器禁用；配置动态选项源时以数据源为准，原静态选项仍保留。

填写**占位文字**并开启**允许从菜单清空**后，用户可在下拉菜单中选择占位项，将值设为空字符串；未开启清空时，自动生成的占位项不可选。已手动创建空值选项时，保留它的文字与禁用状态。未配置上述字段时延续原生首项选择行为。正文色和占位色可分别调整。React/Vue 保留原生选择、键盘、焦点/变化/失焦事件和表单语义；shadcn 遇到动态选项或自动空值项时会提示并使用原生控件。Vue 的静态默认选项也已修正。

普通纯色下拉框的编译预览将箭头向内收，右侧至少留出 12px，并为文字预留箭头空间；已有更大的右内边距仍保留。图片、渐变、多层或绑定背景、响应式右内边距、从右到左布局，以及系统高对比模式继续使用系统箭头，避免覆盖设计设置。两个增强开关均关闭时，实际弹出菜单仍由浏览器提供。

画布显示闭合态的初始选项文字、占位提示、箭头、内边距、截断与禁用内容。可读取页面/文档状态初值及简单动态选项路径；不会执行计算表达式、请求远程数据或模拟预览中的实时选择。已有模板 `.fig` 重新打开即可使用新绘制，无需重生成。本地 `.fig` 回读保留选项及新属性；Figma 兼容导出投影显示静态文字/占位提示，真实 Figma 软件验收仍需单独执行。

在 Select 属性中开启**展开后搜索**，即可按显示文字过滤选项，英文不区分大小写，也支持中文；搜索过程不会改动提交值。大数据列表可独立开启**虚拟滚动**：React/Vue 编译预览和导出只挂载可见的固定高度选项行与少量缓冲行。两项默认关闭，支持静态选项、动态选项源与 React shadcn 输出。搜索只处理已经传入控件的数据，不会请求远程分页；过滤仍需扫描数据，虚拟滚动也不会减少文档中保存的数据量。

方向键和 Page Up/Down 移动到可用选项，Enter 确认，Escape 取消。关闭菜单会清除搜索，再次展开时定位当前选项。清空、手动空值选项、禁用项、值绑定和字段校验保留原有含义。画布仍显示关闭状态，请在编译预览中验证展开行为。虚拟列表采用固定行高，长文字省略显示，悬停可查看全文。这些能力限于 Web 输出；未新增原生移动端、多选/标签模式、选项分组或远程加载支持。

选择单选组（RADIO）后，经典与专注模式会在设计面板前部显示**单选组**设置，可添加、删除或更名选项，设置默认选中、组名、无障碍名称、禁用状态和值绑定。选项文字同时也是实际值；更名会同步该控件的静态默认选择，删除或清空默认项会取消默认选择，支持一次撤销。已有值绑定优先，默认选择会禁用；调整绑定状态的初始值时，应在页面或文档状态中修改，选项编辑不会自动重写共享状态。

画布显示静态选项、单选圆环、初始选中项与禁用外观，支持中文字体回退及节点边界裁剪。初始选中项读取控件默认值或有效的页面/文档字符串状态默认值；画布不运行选项点击或业务事件，实际切换请在 React/Vue 预览中验证。动态选项源与运行期表达式仍以预览为准。此显示修复无需重新插入已有 RADIO 节点，也不改变 `.fig` 的节点类型或持久化协议。

开关（SWITCH）与日期选择（DATEPICKER）也会在画布显示静态初始外观，优先读取有效的页面/文档绑定状态初值，否则使用控件的 `checked` 或 `value`，禁用时内容淡化。开关按节点实际宽高绘制完整胶囊轨道，滑块随可用空间调整，并留在内边距和边框内。画布、React、Vue 与 React shadcn 共用开启蓝色、关闭灰色和白色滑块；开关采用专用基础配色及胶囊形状，通用填充与圆角数据仍保存在节点中。生成控件保留键盘焦点提示、减少动画偏好，且只有一个滑块；画布显示初态，不模拟实时悬停、焦点、响应式或自定义网页主题样式。

日期原样显示有效的 ISO `YYYY-MM-DD`，不做时区转换；空值或无效日期显示格式占位 `YYYY-MM-DD`，只读日期不显示日历按钮。文字与图标遵守内边距和边界裁剪。

本次显示补齐不会修改模板或节点尺寸，已有 `.fig` 无需重新生成。画布不会切换值、打开日历或运行业务事件，实际交互请在 React/Vue 预览中验证；原生日期控件的样式与本地化日期格式可能随浏览器和操作系统不同。

字段的事件面板可以选择**值变化时**、**获得焦点时**或**失去焦点时**；按钮提供点击、焦点与失焦事件，表单保留提交事件。每个事件独立编辑和撤销，其他事件不会被覆盖。字段事件表达式可通过 `$value` 读取原生值，通过 `$event` 读取事件。复选框与开关的布尔值应通过绑定或 `$event.target.checked` 读取；`$value` 保留原生 value 语义。

选择 shadcn 输出时，配置了点击、变化、焦点或失焦业务动作的组合字段会使用原生控件，以保留真实 DOM 事件、受控写入与校验。静态选项包含空值的 Select 也使用原生控件。编译器显示 `ui-kit-native-control-fallback` 提示，这些字段的外观可能与 Radix 控件不同；其他受支持字段继续保留 shadcn 外观、无障碍名称、禁用态和禁用选项。

生成样式包含实际输出的组件所需的工具类，包括图标尺寸和弹层状态；预览不依赖扫描生成项目之外的文件。

### 插入基础组件或常用组合

打开 **Assets（资产）**，将来源切换为**组件模板**，再按**基础组件**或**常用组合**筛选。搜索支持英文名称、中文名称与稳定模板 ID，收藏只保存在本机。插入后得到带有适用绑定、事件及校验的可编辑图层；一次撤销会移除整次插入及其新增状态。同一模板的副本互不共享示例状态；纯模块示例的状态只保留在各自运行中的组件里。

单行与多行输入模板采用一致的文字内边距、紧邻字段的标签和可见焦点反馈，图层及外观仍可编辑。模板配方更新作用于新插入的副本，不会自动重设文档中已有副本的样式。

**组织架构图（Org Chart）**需先安装启用插件，可从 `org-chart` 模板插入。在可视化面板编辑 1–64 张卡片的名称、说明、上级关系，最多八层；支持横向／纵向布局、初始折叠分支以及卡片和连接线配色。窄容器自动采用缩进纵向布局以保持卡片可读，拉宽容器后显示完整横向或纵向树。整组应用可一次撤销。画布展示设计初值，React/Vue 支持分支折叠和键盘导航；配置变化或组件重建时恢复设计状态。不连接企业通讯录、不持久化运行时折叠、不提交表单或执行工作流。`.fig` 保留普通 FRAME 与模块元数据，Figma 不运行此交互。

**操作引导（Walktour）**需先安装并启用，从 `walktour` 模板开始。在设计面板添加、删除或调整 1–12 个步骤，编辑标题、说明和提示位置；目标从当前组件的唯一命名直属子图层中选择，空目标表示居中概览。目标图层仍使用普通画布工具编辑，全部子内容会正常显示。步骤整组应用支持一次撤销。

点击“开始引导”后，React/Vue 显示高亮与说明，可上一项、下一项、完成、跳过或按 Escape 退出。目标缺失或隐藏时显示明确提示并将该步骤居中，不会自动跳过、点击目标或提交表单。关闭后恢复合理焦点；配置变化或重新挂载会结束旧引导。它不跨组件搜索页面元素、不跨路由跳转、不保存“已看过”记录，也不自动启动。当前浏览器无法打开引导弹层时显示可操作提示，保持原页面可用；微前端输出明确阻止此弹层能力。

当前共 **66 个模板：54 个基础组件、12 个常用组合**。其中包含 `multi-select`、`date-range`、`tree`、`tree-select`、`popover`、`popconfirm`。多选下拉将 `string[]` 绑定到独立页面状态；跨页移动前请检查引用。日期范围与树形选择均可绑定类型匹配的状态和 FORM 字段；两个树模板各自创建独立的页面状态。树形数据最多 128 项、6 层，多选彼此独立，不级联父子项。气泡卡片和气泡确认共用插件；确认只显示本地反馈，不执行保存、删除或业务提交。原生日期外观随浏览器和系统变化。

自动补全与时间选择复用普通 **INPUT 节点**，无需启用插件，可从资产模板直接插入。两者的值均绑定字符串类型的页面或文档状态，接入已有 FORM 校验和提交流程。画布显示关闭状态及绑定初值；交互请在 React/Vue 编译预览中验收。

- **自动补全：**选中单行输入框（Text 或 Search），在设计面板编辑“建议列表”，应用后生效。最多 100 条不重复的单行文字，每条最多 200 字符。建议在本地筛选，方向键移动、Enter 选择、Escape 关闭，Tab 离开时不自动选中。用户也可以保留任意自定义文字，清空会更新同一个值绑定。它与浏览器自动填充不同，不会请求服务器。
- **时间选择：**将输入类型设为 `time`，配置 `HH:mm` 或 `HH:mm:ss` 初值、上下限和秒数步长。最小值晚于最大值代表跨午夜区间。值不含日期和时区。实际选择器和本地显示格式由浏览器／系统决定；画布显示中性的时钟和所配置的精度。无效草稿保留在面板供修改，越界的值保留显示并由浏览器表单约束阻止提交。
- 多选下拉的值绑定面板显示**数组**状态；自动补全和时间选择显示**字符串**状态。切换模式时保留原绑定并提示人工修复，不擅自转换业务数据。

React/Vue 支持这些输入类型。`.fig` 保存、重开保留普通 INPUT 元数据；Figma 软件本身不会运行这些低代码交互。

`date-time-picker`、`number-input`、`password-input` 又提供三个可编辑 INPUT 示例，复用现有值绑定、FORM 校验和事件，无需安装插件。画布显示设计初值和控件外观；实际交互在 React/Vue 运行预览中进行。

- **日期时间：**输入类型选择 `datetime-local`，绑定字符串。初值、最小值和最大值使用有效公历日期的 `YYYY-MM-DDTHH:mm` 或 `YYYY-MM-DDTHH:mm:ss` 格式，步长为正整数秒或 `any`。值不含时区，不进行 UTC 转换。与仅时间的跨午夜区间不同，日期时间最小值不能晚于最大值。浏览器／系统的实际选择器格式可能不同于画布；无效草稿留在面板供修改，越界初值保留显示并由原生表单约束阻止提交。
- **数字输入：**步进设置保留“原生”时沿用浏览器控件；选择“自定义”可把按钮放在右侧或两侧；选择“隐藏”不显示步进按钮。自定义按钮使用原生 `stepUp`／`stepDown`，遵循小数步长、上下限、禁用和只读状态。模板采用字符串状态以保留空值；绑定 number 状态时，未完成草稿不会写成 0 或 NaN，合法的 0 则会写回。必填的未完成草稿阻止提交；非必填草稿在失焦或提交时恢复到当前业务数字。接受 FORM 重置后恢复声明初值。原生控件的编辑中间态显示可能随浏览器不同。`step=any` 没有确定增量，自定义步进按钮会禁用，但仍可自由输入数字。
- **密码输入：**明确启用显隐按钮后，默认仍为遮蔽。显隐只影响当前实例，重置、相关类型／配置变化或重新挂载后恢复遮蔽。只读密码可以查看，禁用控件不能切换。显隐不触发值修改事件或表单提交。模板从空值开始，不输出明文值反馈，也不保存凭据；请勿把真实密码写入设计初值、示例状态或设计文件。

Expo、Flutter、原生微信小程序、Taro、uni-app 与 Mpx 源码输出会省略未支持的 `time`／`datetime-local` INPUT 类型和增强输入控件，并给出节点级警告。未配置增强功能的原生数字／密码输入保持既有目标行为。系统选择器、真实辅助技术和其他设备仍需分别验收；生成控件不代表已具备后端校验或凭据存储。

**通用分页（Pagination）**需在插件设置安装并启用，可从资产插入分页或分页列表模板。在设计面板设置总条数、每页条数、初始页码、首尾按钮、密度、字号和配色；窄容器自动减少页码，必要时显示“当前页 / 总页数”并收起首尾按钮。按钮数量不随总页数无限增长。

在“分页绑定”中，把当前页绑定到数字类型的页面或文档状态；总条数与每页条数可读取数字状态或表达式。用户翻页更新同一个绑定，列表需用该状态配置行显示条件或业务查询。组件自身不请求服务器、不提交 FORM，也不自动重试请求。无绑定时仅保留当前实例的页码。空数据展示 `0 / 0` 并禁用导航；总量减少时只将显示页码限制到有效范围，不隐式改写业务状态，因此相关列表也应使用有效页码或在筛选事件中明确重置页码。非法绑定不会被悄悄替换为设计默认值。

“分页列表”示例使用可编辑本地记录和独立页面状态，展示翻页如何改变列表；这不是远程分页或大数据虚拟列表。画布展示静态设计配置，实际状态联动在 React/Vue 运行预览验证。`.fig` 保留模块配置和绑定，Figma 不运行这些分页交互。

**颜色选择**模板复用 `INPUT` 的 `color` 类型、字符串值绑定和现有 FORM 通路。在设计面板通过色块或完整的 `#RRGGBB` 设置初值，空值表示尚未选择。React/Vue 中可直接输入十六进制颜色，点击旁边的色块打开浏览器／系统选择器，选择后更新同一绑定。只读会禁用选择但保留表单提交值，禁用字段不参与提交。必填项拒绝空值，无效颜色保留原值供修复，不会被系统选择器的黑色回退悄悄替换。不支持透明度、CSS 命名颜色或广色域格式。画布展示设计初值的色块与 hex，不打开系统选择器。

**描述列表**是需明确安装并启用的内置插件，用于只读展示标签／值。在插件设置中启用后插入模板或模块；设计面板可成对编辑 1–24 项，整组“应用”只产生一次撤销，“取消”放弃草稿。可配置 1–3 列、标签在左或在上、密度、边框、颜色和字体。窄容器自动减列，运行时长内容在容器内滚动。内容为纯文本，不执行 HTML，不绑定 FORM 或远程数据。画布与 React/Vue 复用布局规则，网页输出语义化描述列表；其他源码目标明确警告并省略模块。两项新模板均用普通节点元数据保存到 `.fig`，不代表 Figma 软件支持其运行交互。

新增提示说明、加载占位、内容空状态和搜索无结果四个基础模板，可在模块面板调整文字与样式。占位模块不会自动识别业务状态；请配置显示条件。Tooltip 的提示内容在运行预览中悬停或聚焦查看，画布仅展示触发器。

这些是可导出 React 与 Vue 的本地示例。搜索按完整示例名称 `Alpha`、`Beta`、`Gamma` 匹配，区分大小写。表单和偏好操作的反馈只表示当前运行中的本地状态，不代表写入服务器或刷新后仍然保留；文件选择器不会上传文件。模板不会配置登录、数据库、后端 API 或全局设计变量。

### 在弹窗和标签页中放入可编辑内容

在 Modal 或 Tabs 模块下创建一个有名称的直接子框架，再把普通字段、表单、按钮或列表放入该框架。在模块属性中，将它选为弹窗正文或对应页签的**内容子图层**。每个被选中的直接子图层名称必须唯一；重命名或删除后，需要重新选择。复制与 `.fig` 保存恢复会保留基于名称的映射。编译时按名称解析映射，因此使用同名直接子图层替换原图层，也会替换映射内容。

映射内容会替代原来的正文文本。启用内容映射后，未映射子图层不会作为触发按钮或页签公共内容显示。缺失、名称歧义或重复使用的映射会产生诊断，不会把内容放入其他位置。未配置映射的旧文档保持原有行为。Tabs 只挂载当前页签；需要切换后保留的草稿应绑定到页面或文档状态。Modal 内置底部按钮仍用于关闭弹窗；业务提交及反馈请使用正文内的 FORM 和 BUTTON 配置。

设计画布中的 Tabs 内容映射只显示模块属性配置的**初始页签**。需要查看或编辑另一页时，修改此设置；运行时点击切换请使用网页预览。当前内容层位于横向标签栏下方或纵向标签栏右侧，正文保留 16 px 内边距，填充尺寸随可用区域变化。未激活和未映射的子层仍保留在图层树与文档中，但不参与画布绘制或指针命中。更新编辑器后重新打开已有 `.fig`，也会按此规则布局，无需反复开关外层自动布局来修复重叠。

表单包含映射的模块内容时，提交校验与错误汇总只处理当前已挂载、且实际属于该表单的字段。未激活页签、关闭弹窗、未映射内容和嵌套表单中的字段不会阻止外层表单；当前页签的必填项仍会阻止提交。异步校验期间如果切换了字段集合，需要在新面板就绪后重新提交，旧结果不会提交新面板。

React 与 Vue 导出均支持上述内容映射，以及 Table、本地 DataGrid 和 Tabs 运行时。DataGrid 保留有界本地数据、排序、筛选、选择、分页与 CSV 操作，与 Backend LIST 分开，不会自动读取服务端分页或保存编辑记录。翻页或临时筛选不会清空已选行。状态区域显示已选总数及其中不在当前页的数量，**清除选择**会同时清空可见与隐藏选择。**清空列筛选**只移除用户输入的查询并回到第一页，保留设计配置中的数据过滤、排序、选择和本地导入数据；空结果页禁用全选。反馈按表格或文档语言显示中文或英文。Vue 远程异步校验仍明确不支持。

验收时插入两份独立控件或模块，分别编辑事件、撤销一次，并在草稿打开时切换选择或文档。在两种生成目标中检查字段事件与校验、弹窗内表单、键盘切换页签、绑定草稿保留，以及内容映射失效后的提示。浏览器回归不能替代真实桌面、物理键盘/输入法或读屏器验收。

### 预览前检查表单配置

选中表单或其中的字段后，可在属性面板查看表单配置概览，串联**字段绑定、校验规则、提交事件、失败处理**四项信息。通过对应行的定位操作，选中相关字段或表单，并打开已有的绑定、校验或事件面板。查看和定位不会修改文档。

可选字段不必设置校验规则。配置了失败分支或错误状态，也不代表一定能保留输入：自定义动作仍可能清空值或跳转页面。建议把重置输入放在提交成功分支，并在发布前测试一次请求失败。按钮点击动作可能绕过表单提交校验，需要校验的提交应配置在表单的 `onSubmit` 中。Vue 导出继续明确拒绝远程异步校验，不会静默提交未经校验的表单。

### 后端列表状态

绑定后端资源的列表，会在生成的 React 和 Vue 应用中显示请求状态：

| 状态     | 行为                                                     |
| -------- | -------------------------------------------------------- |
| 加载中   | 首次请求尚未完成，不表示查询结果为空。                   |
| 刷新中   | 同一查询、同一会话刷新时，保留上次成功结果。             |
| 暂无记录 | 请求成功，但没有返回记录。                               |
| 请求失败 | 显示局部提示和**重试**入口；刷新失败时可能保留上次结果。 |

查询条件、页面订阅或账户变化会使旧结果失效；认证和权限失败会清空保留的数据。重试只重新读取列表，不会重复执行之前的新增、修改、删除或业务命令。已有分页游标和错误文档状态绑定继续生效。这些状态只描述生成应用的请求，不代表数据库迁移、远程同步或生产环境验收结果。

可用“搜索列表＋新增/编辑表单”重复验收：依次测试首次慢请求、有记录时刷新、空结果、读取失败后重试、提交失败保留输入，以及旧请求尚未结束时快速切换查询或页面。React 和 Vue 都应执行同一组场景；模拟接口的浏览器测试与真实身份服务、数据库验收分别记录。

## 地图模块

从 Interactive（交互）工具组选择 **Map**，再在画布上单击或拖动。地图会保存为普通 `FRAME` 与版本化模块配置，因此即使地图运行时不可用，节点仍可显示、编辑并在 `.fig` 往返中保留数据。

画布使用确定性的离线预览；桌面预览和生成应用使用本地安装的 MapLibre GL。经纬度、缩放、交互和标记均由受控配置提供，不注入 CDN 脚本，也不接受任意供应商代码。OpenStreetMap 署名链接始终可见且不可移除。

内置 OpenStreetMap 栅格源支持 0–19 级缩放，其公共瓦片服务适合普通交互浏览，不适合批量下载、离线包或高流量商业用途。此类场景应使用自托管瓦片或未来的供应商适配器，并遵守 [OpenStreetMap 瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)。

AI 与 MCP 使用同一模块注册表：`list_modules`、`create_module`、`read_module` 和 `update_module`。只有受信任的内置/已审查适配器才能创建模块；不能借此执行任意第三方代码。

## 预览

桌面预览面板会把当前页面编译成本地 React 应用，并在设计变化后重新加载。画布与预览之间的桥接可让兼容节点的选中状态保持对应。

- **UI**：选择普通 Tailwind 或受支持的 shadcn/ui 输出。
- **i18n**：启用国际化运行时，并输入 `fr,ar` 这类目标语言列表。
- **Motion**：打开 Motion Debug，检查节点、轨道、触发器、播放状态、进度、减弱动效策略和编译警告。
- **Deploy**：发布前运行只读就绪审计，再执行部署。

预览 sidecar 由 Tauri 启动，因此浏览器版不会显示该面板。预览成功并不等于生产环境已正确配置；还必须验证环境变量、CSP、SPA 路由回退、数据库 RLS 和服务端工作流部署状态。

## 事件、工作流与 Motion

事件与工作流可以更新状态、导航、调用 API/Supabase、执行条件分支，也可使用**播放动效**、**停止动效**、**切换动效**和**等待动效**。Motion 保持为受限的声明式 `MotionSpec` JSON，不接受任意 JavaScript 或 CSS。

**等待动效**支持有界超时和可选的超时停止。多页面应用执行导航动作前，会等待当前页面的 `pageExit` 轨道；等待有四秒硬上限，停滞或无限动画不会把用户困在旧路由。

更完整的 Motion authoring、导出和 Figma Motion Plugin API Beta 限制请参阅[英文低代码应用指南](/user-guide/lowcode-apps#motion-and-workflow-actions)。

需要完整项目源码时使用 `compile`：

```sh
openpencil compile app.fig -o generated-app
cd generated-app
npm install
npm run dev
```

常用参数：

```sh
openpencil compile app.fig -o generated-app --page "Landing"
openpencil compile app.fig -o generated-app --ui-kit shadcn
openpencil compile app.fig -o generated-app --i18n --locale fr --locale ar
```

`--page` 只编译一个页面；不指定时会生成使用 `react-router-dom` 的多页面应用。

## 构建静态文件

生成生产用静态文件：

```sh
openpencil build app.fig -o dist
```

部署在子路径时设置 `--base`：

```sh
openpencil build app.fig -o dist --base /my-app/
```

如果要组合多个独立发布的 React 与 Vue 导出，请使用显式微前端打包参数，并参考
[微前端组合](./microfrontends)构建路由与插槽 Shell；没有这些参数时，原有 standalone
构建路径保持不变。

Supabase 的生产环境公开值应来自环境变量或命令行，而不是依赖设计时回退值：

```sh
VITE_SUPABASE_URL=https://example.supabase.co \
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_... \
VITE_SUPABASE_SCHEMA=app \
openpencil build app.fig -o dist
```

也可以使用参数：

```sh
openpencil build app.fig -o dist \
  --supabase-url https://example.supabase.co \
  --supabase-publishable-key sb_publishable_... \
  --supabase-schema app
```

## Supabase 与运行时就绪检查

根节点的 **Supabase** 面板会区分浏览器公开配置和管理访问：

- 项目 URL、publishable/legacy anon key 与可选 schema 可以进入浏览器运行时。
- 已知 `sb_secret_*`、`sbp_*` Management PAT 和旧版 `service_role` key 会在写入设计或客户端 Bundle 前被拒绝。
- **数据库结构**检查器使用统一凭据存储中的 Supabase Personal Access Token。PAT 不会写入 `.fig` 或响应式编辑器状态；缓存只保存有界、规范化的表/列/关系目录。
- RLS Advisor 生成的是可审查起点，不证明数据库已经应用策略。`UPDATE` 与 `DELETE` 通常还需要相同用户行的 `SELECT` 可见性。

部署前，桌面 Deploy（部署）面板会执行相同的只读检查。AI/MCP 的 `audit_application_runtime` 只报告配置准备度、表命令、schema 不匹配、服务端环境变量**名称**和工作流部署需求；它不会返回秘密，也不会声称检查了实时 RLS 或部署状态。

从配置、RLS、环境隔离到服务端部署的完整清单，请参阅[应用运行时指南](/zh-cn/user-guide/application-runtime)。

## 服务端工作流

文档级服务端工作流与客户端 `lowcodeWorkflows` 相互独立：

- 每个端点都是通过 Supabase 用户身份验证的 `POST` 请求。
- 支持受限表达式、用户范围的 Supabase 查询/变更、条件、返回值、其他已验证工作流和 HTTPS 请求。
- 私密值只能引用服务端环境变量名称，不能写进设计。
- 生成的处理器会拒绝超大/畸形请求、未登录调用、带凭据或指向本地/私有网络的 URL、长时间请求和超大响应；它不会创建 service-role 客户端。

`compile` 会输出：

- `supabase/functions/openpencil-runtime/index.ts`
- `.env.server.example`
- `openpencil-server.manifest.json`
- `SERVER_DEPLOYMENT.md`

`build` 将这些文件保留在 `<outDir>/openpencil-server/`。静态 `deploy` 只上传浏览器文件，并打印手动执行 `supabase functions deploy openpencil-runtime` 的步骤。OpenPencil 不会自动关联 Supabase 项目、上传函数或配置秘密。

托管 Edge Function 会提供新版 `SUPABASE_PUBLISHABLE_KEYS` JSON 字典。生成的 handler 读取其中
的 `default` key；只有整个新版变量不存在时才回退旧 `SUPABASE_ANON_KEY`。新版变量为空或格式
错误会失败关闭。`apikey` 与调用者的 Bearer 用户 JWT 保持分离，handler 仍通过 `auth.getUser`
验证用户身份。

## 部署

`deploy` 会先构建，再上传到指定供应商。

Netlify：

```sh
NETLIFY_AUTH_TOKEN=... \
openpencil deploy app.fig --provider netlify --site my-site
```

Vercel：

```sh
VERCEL_TOKEN=... \
openpencil deploy app.fig --provider vercel --site my-project
```

Cloudflare Pages：

```sh
CLOUDFLARE_API_TOKEN=... \
openpencil deploy app.fig \
  --provider cloudflare \
  --account-id <account-id> \
  --site my-pages-project
```

Cloudflare 也可以从 `CLOUDFLARE_ACCOUNT_ID` 读取账号 ID，或使用 `--site <account>/<project>`。自动化场景可添加 `--json`，获取 provider、deployment ID、URL 和文件数量。

## 安全边界

::: warning 注意
不要把秘密写入设计文件或生成的 SPA。`.fig`、生成源码与浏览器 Bundle 都可能被最终用户读取。
:::

- 低代码输出是静态 React SPA，不是 SSR 或 SSG。
- Supabase 客户端只能使用 publishable/anon key；`service_role`、PAT 和其他管理秘密必须留在凭据存储或服务端。
- Stripe Checkout 与 Customer Portal 动作只负责调用你自己的服务端端点并跳转。`STRIPE_SECRET_KEY`、Webhook 签名秘密、幂等、订阅与客户查询必须在服务端实现。
- Analytics ID 是公开的客户端标识，不是服务端 API key。按需启用 DNT/Consent，并验证部署 CSP。
- Custom Head/CSS 仅支持静态标签和 CSS。不会输出原始 `<script>`、行内事件处理器或外部 JavaScript 模块。
- 多页面 SPA 的托管环境必须把未知路径回退到 `index.html`。
- 供应商 Token 应通过环境变量或 CLI 参数传入，不应进入设计文档。

## 上线前检查

- 桌面预览可打开并渲染目标页面。
- Button、表单校验、成功与错误分支都实际执行。
- Supabase 查询/变更具有加载、空数据和错误状态，并人工验证所需 RLS。
- i18n 目录完整，RTL 页面方向正确。
- `openpencil build app.fig -o dist` 成功。
- 托管平台支持 SPA 回退；刷新深层路由不会返回 404。
- 自定义外部资源符合 CSP；分析与付费动作没有泄露秘密。
- 服务端工作流已单独部署，所需环境变量只存在于服务端。

## 常见问题

- **预览不可用**：请使用桌面应用；浏览器版没有本地 preview sidecar。
- **Supabase 只在预览中工作**：为 `build` / `deploy` 设置 `VITE_SUPABASE_URL` 与 `VITE_SUPABASE_PUBLISHABLE_KEY`，或使用 `--supabase-url` 与 `--supabase-publishable-key`。旧 anon-key 名称仅作为兼容后备；同一来源中的新旧别名若值不同会失败关闭。
- **部署后的路由刷新返回 404**：把主机配置为 SPA，并将未知路径回退到 `index.html`。
- **Cloudflare 上传前失败**：传入 `--account-id`，设置 `CLOUDFLARE_ACCOUNT_ID`，或使用 `--site <account>/<project>`。
- **i18n 有缺失翻译**：检查生成的 `src/locales/_coverage.json` 并补齐目标语言目录。

### 换电脑运行 NestJS 预览与登录恢复

在编译器预览中打开 **NestJS 后端 → 本地托管**，填写连接信息并重新选择本机公开 CA 证书，
然后点击 **检测环境**。面板逐项显示证书、Node.js/npm、Docker、端口、身份服务和 JWKS 的结果。
已有初始化环境还会检查数据库角色及迁移回执；没有环境时显示“未检测”，不会伪装为通过。
检测不会安装依赖、启动服务、执行迁移或修改系统信任库。证书移动后，在高级设置重新选择文件，
再点击“重新检测”。可复制报告只含固定检查码、状态和时间，不包含路径、凭据或原始日志。
切换配置后旧报告会清除。准备和启动按实际阶段显示进度，不使用不准确的百分比。

内置预览等待系统浏览器登录时可点击“取消登录”。取消、超时、浏览器打开失败和会话过期会显示
对应提示及“重新登录”入口。过期后访问令牌和私有页面数据失效；明确重新登录后回到原业务页面，
不会重新提交失败的写入。完整刷新或重启预览仍需重新登录，本轮不持久化 refresh token。
本地退出不等于退出身份服务的浏览器会话，切换账号时可能还需在身份服务选择或退出账号。

网络检测成功不代表真实登录、两账号数据隔离或生产可用。真实桌面、Keycloak 与其他电脑的验收
步骤见 [NestJS 本机与会话验收](/development/backend-nestjs#first-run-on-another-computer-and-session-recovery)。

### 多选与本地选择模块

下拉框的可视化设计面板新增**允许多选**与各选项默认勾选。多选 `value` 绑定字符串数组，单选继续使用字符串；切换前先解除原值绑定，再绑定对应类型的状态。两种模式都支持搜索和虚拟滚动。多选后保持菜单展开，“清空选择”移除所有选择；聚焦已关闭的触发器时，Backspace 移除最后一个可用选项。业务空字符串选项与没有选择的空数组不同。现有事件简写 `$value` 仍表示原生控件的第一个选中值；需要全部值时请使用绑定的数组状态。

在插件管理启用**日期范围**、**树与树选择**或**气泡浮层与确认**，即可从模块工具或资源模板插入。日期范围提供原生日期输入、ISO 初始日期、最早与最晚日期；运行中倒置或未填完整的范围会提示错误，不会自动交换日期。树支持可编辑层级、搜索、独立单选/多选、禁用分支、初始展开及键盘操作。下拉树在设计容器内展开，请为列表保留高度。日期范围与树均支持页面／文档状态及 FORM 绑定；未绑定的树选择仍只保留在当前实例中。两者都不会自动配置后端数据。

气泡浮层支持内容与确认模式，可调整触发器、浮层样式和优先位置。内容子图层是普通可编辑节点，按唯一的直接子图层名称关联；未配置关联时显示纯文本正文。已配置的子图层缺失、重名或无法渲染时，会报告 `module-content-child-invalid` 并保留空内容。Escape、外部点击和焦点离开可关闭浮层。确认与取消只显示本地反馈；需要业务操作时，请在内容中的普通按钮上明确配置事件。现代浏览器使用 Popover 顶层，旧浏览器的容器内回退可能被父容器裁剪。画布显示触发器，通过“编辑内容”编辑子图层，在编译预览中查看展开效果。

本轮验证目标为 React/Vue 网页。原生和移动端会提示不支持的交互。Expo、Flutter、微信小程序、Taro、uni-app 和 Mpx 会省略多选 SELECT 控件，报告稳定诊断 `{target}-select-multiple-unsupported`，其余节点继续导出。`.fig` 继续以普通节点和 OpenPencil 模块元数据保存配置；Figma 不会因此执行这些运行时交互。

### 表单组件绑定、树形选择与级联选择

滑块／范围滑块、评分、日期范围、树／树形选择和级联选择的设计面板提供“值绑定”和“校验规则”。先建立页面或文档状态，再选择类型匹配的可写状态：滑块和评分使用 number，日期起止分别使用 ISO 日期字符串，单选树使用节点 ID 字符串，多选树使用节点 ID 的 string[]，级联选择使用从根到叶的 string[] 路径。树的空字符串／空数组表示清空。计算状态不能作为写入目标。范围的结束值单独绑定、单独校验；清除绑定后恢复组件本地初值。

“字段名称”只设置 FormData 中的键，不重命名绑定的业务状态；留空使用状态名。显式名称最多 64 个字符，须以英文字母或下划线开头，后续只允许英文字母、数字、下划线和连字符；`__proto__`、`prototype`、`constructor` 是保留名称。面板拒绝无效名称；从文件导入的无效名称会得到编译警告，且不写入 FormData。

绑定字段可参与 FORM 必填、范围等校验与表单重置；评分的 0 表示未选择，滑块的 0 可以是有效数值。绑定不存在、类型错误或值无效时会明确显示不可用，不会用模板示例值代替。树绑定指向缺失节点或禁用分支时保持无效，不会改写业务状态；切换单选／多选不会自动转换状态。只读字段保留序列化值，禁用字段不参与提交。重置恢复状态默认值，取消重置、隐藏字段和晚到校验按实际表单作用域处理。画布显示设计默认值，不镜像正在运行的预览状态。

Tree/TreeSelect、日期范围和级联选择还可在“值绑定”中设置“只读”。只读字段保持数值可读并参与序列化；树仍可展开和导航，但不能改选。禁用会阻止编辑和树展开、排除提交值，并关闭已打开的 TreeSelect 面板。画布合并模块配置与节点的作者状态，仅显示设计初值；焦点和校验仍属于运行时状态。步骤条淡化禁用步骤，保持只读文字完整可读。RichText 画布使用配置字号、行高及共享字体回退，离线逻辑行预览仍不同于浏览器完整富文本排版。

在“设置 → 插件”启用**级联选择（Cascader）**后，可从模块菜单或 `cascader` 基础模板插入。设计面板支持编辑树形选项、父项、禁用项、初始叶节点，以及颜色、圆角、行高、搜索和清空。React/Vue 支持逐列浏览、完整路径搜索、键盘选择、禁用分支和清空；只选择叶节点才写入路径。最多 128 项、6 层，使用本地配置，不含远程加载、多选或父子勾选。未绑定时保持实例本地状态；绑定不自动配置数据库、网络请求或持久化。

普通 FRAME 和版本化元数据继续保存在 `.fig` 中；这不代表 Figma 能执行这些交互。真实 Tauri、另一台电脑字体及系统读屏器仍需单独验收。

只读控件保留可序列化的值，不阻塞必填等约束校验。模块字段归属外层 FORM；显式 `interactiveProps.form` 跨表单指定暂不支持，编译器会禁用该控件并给出警告。
