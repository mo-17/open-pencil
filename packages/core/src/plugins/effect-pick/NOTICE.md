# EffectPick selected local adaptations

These fixed CSS/SVG templates are adapted from the user's local `@effect-pick/collection` inputs under authorization for local integration. The original twelve entries retain their 0.6.0 identities; the next twenty record the inspected 0.7.0 source version. The collection declares `UNLICENSED`; each catalog entry preserves the recorded source status, and distribution rights for reference sources without license evidence remain unreviewed. The surrounding OpenPencil package license does not replace this status.

The catalog records each reference URL, author, source mode, original source SHA-256 values and the adapted markup/CSS digest. Reference authors identify the visual inspiration; these templates are not represented as their complete original CodePen code. Cards use bounded hover/focus transitions rather than the original pointer-following or stateful control APIs. No original collection JavaScript is executed and no demo pages, remote assets or full collection registry are included.

Generated user projects must retain the selected effects' provenance and the `UNLICENSED`/unreviewed status. Public distribution requires a separate license review.
